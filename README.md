## ✨ 이런 일을 해 왔습니다

**⚡ 대시보드를 빠르게**
- 아이템마다 `Suspense`로 로딩을 나눠, 전체 화면 로딩 대신 **준비된 차트부터 바로 표시**
- 메모이제이션과 가상 스크롤로 **대용량 그리드의 불필요한 재렌더링 제거**
- 대용량 엑셀 생성을 브라우저에서 **서버로 옮겨 화면 멈춤과 다운로드 실패 해결**

**🧱 고치기 쉬운 구조로**
- 아이템을 **Container/Presentational**로 나눠 데이터 처리와 화면 표시를 분리
- Redux 상태 8개를 모으던 보고서 저장을 **Custom Hook 하나(Facade)**로 감싸 화면 코드를 단순화
- 데이터 가공은 **순수 함수**로, 오류 처리는 **모나드 체이닝**으로 한 곳에 모아 수정 범위를 예측 가능하게

**🧩 사용자 기능을 디자인 패턴으로**
- **Observer**: 한 차트에서 클릭한 값과 연관된 데이터를 다른 차트에서 강조
- **Memento**: 옵션 변경 히스토리와 원하는 시점으로 되돌리기
- **Command**: 쿼리 편집기 실행 취소 · **Composite**: 폴더·보고서 트리 Drag & Drop

**🔐 서버 · 보안 · 운영**
- 고객사 SSO 연동과 장애 대비 비상 로그인, 요청 본문 암호화로 보안 점검 일괄 조치
- BI 솔루션을 **고객사 10곳 이상**에 구축하고, 운영 중 **개선 30건 · 이슈 70건 이상** 해결
